# Wearable Rhythm Guidance — UX Research Case Study

Static responsive English-first case-study website based on the original NUS CDE5312 Team 5 report. Includes real prototype and user-testing photographs, study data, interactive metric comparison, image lightbox, and a link to the original report.

## How to use
Open `index.html` locally, or deploy the folder to Netlify / Vercel as a static project. No API key, build tools, or dependencies are required.

## Publication notes
- This was a team project by Zhang Jingtong, Zhou Ziqin, Sun Yingchao and Wang Yujie. Please confirm personal responsibilities before adding a detailed individual role claim.
- Study had 6 participants, all female aged 21–24; do not overgeneralize.
- Normalized metric scores are reproduced from Tables 1 and 2 of the source report.
- Check participants' consent before publicly sharing the user-testing photo and report. If consent is unclear, remove or blur identifiable imagery and consider withholding the complete report.
- Fonts are loaded from Google Fonts when online; system fallbacks work offline.
